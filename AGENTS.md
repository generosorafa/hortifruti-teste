# Instruções para agentes

Antes de analisar ou modificar este repositório, leia integralmente [CONTEXTO_PROJETO.md](CONTEXTO_PROJETO.md).

O fluxo de Issue classificada e Pull Request vinculado descrito nesse documento é obrigatório. Nenhuma implementação deve começar sem Issue, e nenhuma entrega deve ser enviada diretamente para `main`.
